# fruits-demo（Git + GitHub 实战练习仓库）

跟随 B 站教程《Git+Github核心概念大串讲》动手实操的练习仓库，用一份「水果清单」走完 Git 全流程。

## 已实操的概念

- git init / .gitignore
- 工作区 → 暂存区(add) → 本地仓库(commit)
- 三种撤销：restore(discard) / reset --hard / revert
- 分支 branch：创建、切换、合并 merge、删除
- HEAD 与分离头指针 detached HEAD
- 合并冲突 merge conflict 的产生与解决
- worktree 工作树、stash 临时存储
- cherry-pick 拣选提交、rebase 变基
- 远端：push / clone / pull / Pull Request
